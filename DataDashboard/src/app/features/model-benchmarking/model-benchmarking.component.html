How score and metrics are calculated
Success %: successful requests / total dataset rows for that model.
Avg ms: average response latency in milliseconds (lower is better).
P95 ms: 95th percentile latency (tail latency; lower is better).
Req/s: throughput (successful requests per second; higher is better).
Accuracy %: shown only when both Expected path and Prediction path are provided and resolvable.
Selected metrics: output models calculate local classification/regression metrics; metric/evaluator models read returned metrics declared by daimo:metrics.
Score: relative 0-100 ranking score using the active ranking metric, success rate, and latency. Lower-is-better metrics such as RMSE/MAE/MSE are inverted.
Click a metric column to use it as the ranking metric.
